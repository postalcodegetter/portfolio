03 · Independent project

Smart Market AI, built to doubt itself.

  • Python
  • scikit-learn
  • pandas
  • SQLite
  • Streamlit
  • Plotly
View on GitHub
The problem
Most trading backtests flatter themselves. I wanted a system whose main job is to find out, honestly, whether a model actually works, and to refuse to certify it when it doesn't.
What I built
An end-to-end ML research system for systematic equity signals, with walk-forward validation, a held-out final test the model never sees during tuning, and a deployability gate with explicit thresholds.
  • Walk-forward pipeline comparing logistic regression, random forest, gradient boosting and an ensemble across 58 engineered technical and market features.
  • Regime-aware routing: separate specialist models for bull, bear, high-volatility, mean-reversion and neutral conditions.
  • Five-part audit suite on every training pass: feature redundancy, temporal stability, probability calibration, concentration, and Monte Carlo trade-shuffle robustness.
  • Overfitting defences: purged walk-forward CV with embargo and a deflated Sharpe gate that accounts for the 91 threshold configurations tried.
  • Risk controls: ATR-scaled stops and targets, sector and daily trade caps, an equity drawdown breaker, loss cooldowns.
  • Closed loop: logs live predictions to SQLite, checks real forward outcomes, and feeds them back into a pattern memory.
  • Trading-terminal UI: rebuilt the default Streamlit layout into a single-file dashboard with candlesticks, correlation matrices, sector treemaps and equity/drawdown curves, leaving every backend function untouched.

Warp 04Flying to The Reels Bot

04 · Independent project

A bot that makes short videos on its own.

  • Python
  • Groq LLM
  • Google Cloud TTS
  • MoviePy / FFmpeg
  • Pillow
  • Instagram Graph API
View on GitHub
The problem
Producing vertical video is slow, repetitive, manual work. I wanted to see how much of it could run with no human in the loop.
What I built
A bot that sources content, rewrites it with an LLM, narrates and captions it, renders the video, and publishes it as an Instagram Reel on its own.
  • Captions locked to speech: SSML timing marks from Google TTS drive caption timing exactly, rather than guessing word durations.
  • Custom rendering: animated, emoji-aware captions drawn with Pillow and composited programmatically with MoviePy and FFmpeg.
  • Content screening: RSS ingestion, HTML cleanup, a blocklist for sensitive topics, de-duplication of used stories, and a sanitiser that strips LLM meta-commentary from the script.
  • Built to fail gracefully: if the LLM call fails, a local rewriter takes over; uploads retry with back-off before the run gives up.
  • Several formats from one codebase: long-form narrated stories and short caption-only clips, each with its own prompt and layout.
One run, end to end7 stages
  1. IngestRSS feeds parsed, HTML stripped
  2. ScreenBlocklist, length and duplicate checks
  3. RewriteGroq LLM with a custom system prompt, output sanitised
  4. NarrateGoogle Cloud TTS with SSML marks
  5. RenderMoviePy / FFmpeg, 1080×1920, synced captions
  6. UploadCloudinary with retry and error handling
  7. PublishInstagram Graph API container, wait, publish
